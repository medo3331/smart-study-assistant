## القرار المعتمد

الألعاب قسم مستقل داخل Magicly له اقتصاده وبروفايله، لكن **مربوط** بالبروفايل
والمجتمع والمتجر — وبيكسب **XP أساسًا**، والكوينز منه **محدودة** عشان يفضل
مكافأة للمذاكرة مش بديل عنها (قرار التصميم: مفيش مزرعة كوينز من الألعاب).

## ١) Arcade Foundation — db/124

| المكوّن | المسؤولية |
|---|---|
| `game_profiles` | بروفايل لاعب لكل لعبة: XP · أفضل نتيجة · عدد لعب · انتصارات — RLS مالك-بس |
| `game_achievements` | إنجازات Arcade المفتوحة — بتتفتح **جوا السيرفر** مرة واحدة (PK مزدوج) |
| `arcade_level(xp)` | level = floor(sqrt(xp)/5)+1 — نفس معادلة `levelFor` في الواجهة (مصدر واحد) |
| `arcade_submit_score` | تسجيل جولة: clamp للنتيجة (0–100k) · XP محسوب على السيرفر (فوز=60، خسارة=5–40 من النتيجة) · حماية الزائر · مكافأة أول فوز/يوم عبر `award_coins('arcade_win')` · فتح إنجازات جديدة |
| `arcade_leaderboard` | Top 20 للعبة — security definer (RLS بيمنع قراءة بروفايلات غيرك) + أسماء من social_profiles |

- مصدر كوينز جديد: `arcade_win` (5 كوين · سقف 1/يوم · live) — ref_id يومي
  بيمنع التكرار، نفس عقد db/113.
- الإنجازات بتاخد مكافأتها من مصدر `achievement` الموجود (سقف 5/يوم).
- الواجهة **ماتبعتش XP خالص** — السيرفر بيحسبه من النتيجة والفوز.

## ٢) Magicly Chess ♟️ — أول لعبة حقيقية

- **محرك كامل** `lib/games/chess/engine.ts`: كل حركات القطع، التبييت
  (قصير/طويل بشروطه)، الأخذ بالتجاوز، الترقية (٤ اختيارات)، الكش،
  كش مات، حصر. pure TypeScript بدون React — قابل للاختبار لوحده.
- **AI** `lib/games/chess/ai.ts`: minimax + alpha-beta، عمق = الصعوبة
  (سهل ١ · متوسط ٢ · صعب ٣) + ضجيج بسيط في السهل. أكل أولًا في الترتيب.
- **واجهة** `/games/chess`: لوحة 8×8 بالـ unicode، دوس واختار (أهداف قانونية
  مميزة، أكل بدايرة)، 3 مستويات صعوبة، حالة الكش/المات، نتيجة المباراة
  (XP + مستوى + كوينز + إنجازات جديدة) من الـ RPC.
- اللاعب أبيض دايمًا، الـ AI أسود. النتيجة تتسجل **مرة واحدة** عند النهاية.

## ٣) ترقية `/games` — Magicly Arcade Hub

- **بروفايل اللاعب**: مستوى Arcade الكلي + شريط تقدم + XP المتبقي للمستوى
  الجاي + كروت لكل لعبة (عدد الجولات) + أحسن نتيجة.
- **اللعبة المميزة**: Magicly Chess.
- **مكتبة الألعاب**: الشطرنج + كل ألعاب Break Zone + غرفة الهروب + الصناديق.
- **مهام اليوم**: ٣ مهام (العب جولة · اكسب مباراة · حسّن رقمك) — القواعد
  منفذة على السيرفر (أول فوز/يوم).
- **الترتيب**: Top 20 شطرنج 🥇🥈🥉.
- **الإنجازات**: 6 إنجازات (نفس معرفات السيرفر) — مقفولة/مفتوحة.
- **على الطريق**: Magicly Run · Magicly Football · Magic Blocks · Battle
  Pass · بطولات موسمية (خطة Gaming Universe).
