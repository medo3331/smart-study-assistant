## ٢) تطوير Magicly Chess ♟️

- **قطع أوضح**: قطع ممتلئة (solid) — الأبيض بحدود غامقة والأسود بحدود فاتحة
  (`-webkit-text-stroke`) + ظل — باينة من بعيد على اللوحتين.
- **لوحة أكبر وأنضف**: إطار خشبي سميك، مربعات بتحوّل ألوان ناعم (transition)،
  قطعك بتتظلل عند الـ hover وبتكبر لما تتحدد.
- **إبرازات**: آخر نقلة (مربعان أصفران) · الكش (دايرة حمرا على الملك) ·
  أهداف قانونية (نقط/إطارات أكل).
- **القوانين 📖**: قسم قابل للفتح فيه شرح كل قطعة + التبييت + التجاوز +
  الترقية + الكش مات/الحصر — بالعربي وبشكل طالب.
- **جانب اللوحة**: الأسرى (بشكل القطع) + سجل آخر النقلات.
- استجابة أسرع: تأخير الـ AI نزل 250ms.

## ٣) Memory Match أسهل 🧠

- **٨ كروت كبيرة (٤ أزواج بس)** بدل شبكة كثيفة — ٢ عمود على الموبايل.
- **تمييز بصري**: كروت ❓ (أسئلة) و💡 (إجابات) — المطابقة بقت واضحة.
- رجوع الكارت الغلط ٧٠٠ms بدل ثانية + عدّاد محاولات + «خلط جديد» بدون reload.
- تصميم متسق مع هوية Magicly (paper/ink/marker بدل الخلفية الغامقة القديمة).
- **مكافأة**: أول إكمال بينادي `claim_break_game('memory')` — نفس عقد البريك.

## ٤) Quiz Rush — أسئلة واقعية 🏃

- الأول: **سؤال من خطة مذاكرتك الحقيقية** (سيرفري — بيتحقق ومكافأته من السيرفر).
- لو سؤال الخطة مش متجهز: **بنك أسئلة عامة** (`lib/games/quiz-bank.ts`) —
  ٢٤ سؤال حقيقي (رياضة/فيزياء/كيمياء/أحياء/عربي/English/حاسوب/تاريخ) متعدد
  الاختيار مع تصحيح فوري وإظهار الإجابة الصحيحة.
- البنك **بدون مكافأة كوينز عمدًا** — الإجابة بيتحقق في الواجهة، فالمكافآت
  حصرة أسئلة الخطة السيرفرية (حماية للاقتصاد). معلن في الواجهة «للتدريب فقط».
