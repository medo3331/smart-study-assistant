# docs/reports — تقارير الجلسات المُنجزة

كل التقارير التاريخية (`FINAL_*` / `PHASE_*` / `DB_*` / `SESSION_*` / تقارير الـ audit) اتنقلت من جذر الريبو هنا.

**ليه:** الجذر كان فيه 106 ملف `.md` — ده بيخلي الملفات المهمة فعلاً (`README` / `AGENTS` / `CLAUDE` / ملفات `*_REAL` الستة) مدفونة وسط تقارير قديمة. التقارير دي سجل قراءة، مش مرجع تشغيل.

**ممنوع تعديل محتواها** — دي أرشيف. أي تقرير جديد بيتكتب مباشرة في `docs/reports/` أو `docs/` حسب نوعه.

**ملاحظة:** `EXAMS_PHASE1_AUDIT.md` و `EXAMS_PHASE2_PROPOSAL.md` فضلوا في الجذر عمداً — ملفات محمية بقرار `D-DEV-023` (DEV-02 خارج النطاق).
