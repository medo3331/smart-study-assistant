القاعدة (متفق عليها مع المستخدم): في أي تصميم أو اعادة تصميم صفحة في smart-study-assistant:
1. حمّل المهارة (load ui-ux-pro-max-skill).
2. صف المنتج + الـ stack (nextjs/react).
3. ولّد نظام التصميم: DesignSystemGenerator → pattern / style / colors / typography / effects / anti-patterns / checklist.
4. اعمل preview أول (mockup HTML / screenshot) واعرضه.
5. انتظر موافقة المستخدم صراحة.
6. نفّذ التعديل.
7. تحقّق: responsive 375/768/1024/1440 + WCAG AA 4.5:1 + لا رموز تعبيري كأيقونات (Lucide/Heroicons) + cursor-pointer + prefers-reduced-motion + حالات التحميل/الخطأ/الفارغ/النجاح.

لا تعدل أي كود تصميم بدون preview وبدون الرجوع لقائمة anti-patterns وpre-delivery checklist من المهارة.
